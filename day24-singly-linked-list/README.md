# Day 24 - Singly Linked List Implementation

## Project

A console-based Singly Linked List implementation built using Object-Oriented Programming (OOP) in Python. The program uses a menu-driven interface to perform common linked list operations by creating and managing nodes manually.

## Features

- Add node at the end
- Display linked list
- Search for a node
- Delete a node
- Count total nodes
- Check if the linked list is empty
- Clear the linked list
- Menu-driven interface

## Concepts Practiced

- Classes and Objects
- Object-Oriented Programming (OOP)
- Linked List data structure
- Nodes and references
- Traversing a linked list
- Helper functions
- Loops
- Conditional statements
- Menu-driven programming

## What I Learned

- A singly linked list stores data as a chain of nodes, where each node points to the next node.
- Creating separate `Node` and `LinkedList` classes makes the code more organized and follows object-oriented design.
- Traversing a linked list requires moving from one node to the next using the `next` reference.
- Insertion at the end requires finding the last node before linking the new node.
- Deleting a node requires keeping track of both the current node and the previous node to reconnect the list correctly.
- Helper methods like `check_if_list_is_empty()` reduce repeated code and improve readability.
