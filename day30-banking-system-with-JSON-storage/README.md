# Day 30 - Banking System with JSON Storage

## Project

A console-based Banking System built using Object-Oriented Programming (OOP) and JSON file handling. The program uses a menu-driven interface to perform common banking operations while storing account records permanently in a JSON file.

## Features

- Create account
- View all accounts
- Search for an account
- Deposit money
- Withdraw money
- Transfer money between accounts
- Delete an account
- Save account records to a JSON file
- Load account records from a JSON file
- Prevent duplicate Account Numbers
- Validate positive transaction amounts
- Menu-driven interface

## Concepts Practiced

- Classes and Objects
- Object-Oriented Programming (OOP)
- JSON File Handling
- Reading and Writing JSON Files
- CRUD Operations
- Lists and Dictionaries
- Helper Functions
- Input Validation
- Searching
- Menu-driven Programming
- Data Persistence

## What I Learned

- JSON provides a structured and readable way to store application data.
- Account records can be saved and loaded using Python's `json` module.
- Automatically saving data after each operation ensures records remain up to date.
- Separating banking operations into class methods improves code organization and maintainability.
- Input validation helps prevent invalid account information and transaction amounts.
- Banking operations such as deposit, withdrawal, and transfer require careful validation to maintain data consistency.
- Combining OOP with JSON storage makes applications more practical by preserving data between program executions.
